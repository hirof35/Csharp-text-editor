Custom Pixel-Grid EditorWPF (Windows Presentation Foundation) の標準的なテキストレンダリングを排し、ピクセル単位での正確な文字配置を追求したテキストエディタ・コアエンジンです。開発の背景と目的一般的なWPFの TextBox や RichTextBox は、高い表現力を持つ反面、フォントのヒンティングやアンチエイリアスの影響で、等幅フォントであっても微妙な描画のズレが発生することがあります。本プロジェクトでは、「1ピクセルの狂いもない格子的整列」を実現するため、WPFの抽象化レイヤーを介さず、低レイヤーな描画制御を用いてエディタを再構築しました。技術的特徴1. 物理グリッド・レンダリングWPFの FormattedText を使用しつつも、TextFormattingMode.Display を強制。文字を1文字ずつ独立した座標に配置することで、OS側のサブピクセル配置による累積誤差を完全に排除しました。2. マルチバイト（全角）/ タブ文字の同期制御文字コード（ASCII境界）に基づいた動的な幅計算ロジックを実装しています。全角文字: 半角の正確に2倍の幅として計算。タブ文字: \t を検知し、専用の可視化記号（→）を黒色で描画。3. 論理座標と視覚座標の完全同期GetCaretX メソッドにより、データ構造上のインデックスから物理的なX座標をリアルタイムに算出します。これにより、全角・半角・タブが混在した行においても、キャレット（カーソル）が常に文字境界へ精密に吸着します。4. ロジスティクスを考慮したデータ管理ObservableCollection<EditorFile> によるタブ管理システムを搭載。複数のファイルを独立したバッファとして保持し、UIとデータの整合性を保ちます。実装環境Language: C# 12.0 / .NET 8.0 (WPF)Architecture: MVVM-Ready PatternCore Logic: Custom FrameworkElement.OnRender Override操作方法キー / 操作挙動文字入力1文字ずつグリッドに配置（全角対応）Tabタブ文字（可視化記号付き）を挿入Enter行分割およびインデックスの再計算マウス左クリック文字幅を考慮した最近傍の境界へカーソル移動今後の展望シンタックスハイライト: トークナイザの実装による予約語の着色。レンダリング・キャッシュ: DrawingVisual を用いた変更行のみの差分更新による高速化。仮想化: 数万行のファイルを開いた際のメモリおよび描画の最適化。ライセンスこのプロジェクトは、自律と自己責任の原則（「自灯明」）に基づき、技術的真実を追求するために開発されました。
